DESIGN SYSTEM

Editorial-first. One accent. Reward in amber.

Near-grayscale monochrome so reading surfaces stay quiet; the cobalt accent appears only for actions, links, and focus. Early-reader figures read in a quiet amber — text only, never a filled badge — so the mechanic never shouts.
